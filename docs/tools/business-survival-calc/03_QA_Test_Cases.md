# QA Test Cases — 사업 생존기간 계산기

기준 문서: `11_BenefitsON_QA_Test_Standard_v1.0`.
자동 회귀: `node engine/survival-calculator.test.js` (아래 QA-01~08 그대로 구현).

## 계산 시나리오

입력 순서: 현재 보유 현금 / 월평균 매출 / 월 변동비 / 월 고정비 / 월 기타 유출 / 최소 유지 현금

| # | 입력 | 기대 결과 |
|---|---|---|
| QA-01 | 30,000,000 / 10,000,000 / 4,000,000 / 7,000,000 / 1,000,000 / 5,000,000 | 월 현금흐름 −2,000,000 · 생존 `약 12개월 15일` · **SURV-002 주의** (적자) |
| QA-02 | 20,000,000 / 10,000,000 / 4,000,000 / 7,000,000 / 1,000,000 / 5,000,000 | 생존 `약 7개월 15일` · **SURV-002 주의** |
| QA-03 | 10,000,000 / 10,000,000 / 3,000,000 / 3,000,000 / 1,000,000 / 0 | `현금 감소 없음` · **SURV-001 안정** (흑자) |
| QA-04 | 3,000,000 / 1,000,000 / 0 / 2,000,000 / 0 / 5,000,000 | `이미 안전 현금 이하` · **SURV-005 위험** |
| QA-05 | 999,999,999,999 / 1,000,000 / 0 / 1,000,001 / 0 / 0 | `10년(120개월) 이상` · **SURV-002 주의** (적자이면 상한이어도 최대 주의) |
| QA-06 | 상태 경계: 고정비만 1,000,000, 현금 2,000,000 / 3,000,000 / 6,000,000 / 80,000,000(적자), 그리고 매출 2,000,000·고정비 1,000,000(흑자) | 각각 **SURV-004 위험 / SURV-003 경고 / SURV-002 주의 / SURV-002 주의(80개월이어도 적자) / SURV-001 안정(흑자)** |
| QA-07 | 30,000,000 / 10,000,000 / 4,000,000 / 7,000,000 / 1,000,000 / 0 | 시나리오 6행. REV-10: 매출 9,000,000·변동비 3,600,000. FIX-20: 고정비 5,600,000 |
| QA-08 | monthlyCashFlow({100,10,20,5}) | 65 |

## 입력 검증

| # | 입력 | 기대 |
|---|---|---|
| QA-V1 | 월 변동비(12,000,000) > 월평균 매출(10,000,000) | `variable` 인라인 오류, 결과 미산출 |
| QA-V2 | 월 기타 유출(20,000,000) > 월평균 매출(10,000,000) | `other` 인라인 경고, **결과는 산출** |
| QA-V3 | 필수 5개 중 일부 미입력 | 결과 대기 상태 유지, 오류 없음 |
| QA-V4 | 콤마 입력 (30000000 → 30,000,000) | 실시간 천단위 콤마, 커서 위치 유지 |

## localStorage

| # | 동작 | 기대 |
|---|---|---|
| QA-S1 | 입력 후 새로고침 | 입력값 복원 (`survivalCalcInputs`) |
| QA-S2 | "계산하기" 클릭 | 최근 계산 기록에 1행 추가 (최대 10건, `survivalCalcHistory`) |
| QA-S3 | 기록 행 ✕ / "전체 삭제" | 해당 행 / 전체 제거, 빈 상태 문구 표시 |
| QA-S4 | "초기화" 클릭 | 입력값·결과 초기화, `survivalCalcInputs` 삭제 (기록은 유지) |
