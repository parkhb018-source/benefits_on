# 디자인 기준 (DESIGN-TOKENS)

시안(`design-reference/`)에서 쓴 값을 그대로 정리했다. 사장님이 보내 준 샘플 UI 이미지(BenefitsON 리뷰 대응 도우미)의 스타일을 따른다. 기존 혜택on 사이트에 공통 스타일이 있으면 **충돌하는 값은 사이트 값을 우선**하고 사용자에게 알린다.

## 색

| 이름 | 값 | 용도 |
|---|---|---|
| `--primary` | `#4458E8` | 주요 버튼, 링크, 선택 테두리, 로고의 `on` |
| `--primary-dark` | `#3547C9` | 연한 파란 바탕 위 글자, 선택된 칩 글자 |
| `--primary-light` | `#EEF1FF` | 선택된 칩 배경, 안내 상자, 연한 카드 |
| `--primary-border` | `#D5DBFA` | 연한 파란 카드·태그 테두리 |
| `--text` | `#1E2340` | 본문 글자 |
| `--muted` | `#5F6588` | 보조 글자(설명, 고지) |
| `--border` | `#E3E7F7` | 카드·입력창·칩 테두리 |
| `--surface` | `#F5F7FF` | 화면 바탕(결과·확인·답변·체크리스트 화면) |
| `--white` | `#FFFFFF` | 카드 배경, 처음·붙여넣기 화면 바탕 |
| `--amber-bg` / `--amber-border` | `#FFF6E6` / `#FBE3B5` | 주의 카드·상자 |
| `--amber-text` / `--amber-icon` | `#7A4200` / `#D97706` | 주의 글자·아이콘 |
| `--green-bg` / `--green` | `#EAF7F1` / `#17835A` | 개인정보 안내 상자 |
| `--blank-bg` / `--blank-text` | `#FFF1C2` / `#5C3D00` | 답변 미리보기의 `[빈칸]` 강조 |
| `--dark` | `#0B0E1F` | 캡쳐 화면 배경 |
| `--toast` | `#1E2340` | 하단 안내 상자 배경(글자 흰색) |

**규칙**: 흰 글자는 `--primary` 위에서만. 연한 설명 글자(`--muted`)는 흰색·`--surface` 위에서만. 색만으로 의미를 구분하지 않는다(주의 상자는 색과 함께 문구로도 구분).

## 글꼴·크기

글꼴 `Noto Sans KR` (400, 500, 700). 사이트 공통 글꼴이 있으면 그것을 따른다.

| 용도 | 크기 / 굵기 |
|---|---|
| 처음 화면 제목 | 28px / 700, 줄 간격 1.4 |
| 화면 제목(헤더) | 18px / 700 |
| 카드 제목, 섹션 제목 | 15px / 700 (처음 화면 카드는 19px) |
| 본문, 입력창 | 16px (본문 설명은 14~15px), 줄 간격 1.5~1.75 |
| 답변 미리보기 | 16px, 줄 간격 1.75, 줄바꿈 유지(`white-space: pre-line`) |
| 보조 설명 | 13~14px, `--muted` |
| 고지(disclaimer) | 12px, `--muted`, 가운데 정렬 |
| 하단 탭 이름 | 12px, 준비중 배지 11px |

| 요소 | 값 |
|---|---|
| 카드 | 둥근 16px, 흰 배경, 1px `--border`, 그림자 `0 2px 10px rgba(68,88,232,0.08)`, 안쪽 여백 18px |
| 주요 버튼 | 높이 54px, 둥근 12px, `--primary` 배경, 흰 글자 17px / 700 |
| 보조 버튼 | 높이 48px 이상, 흰 배경, 1px `--border`, 글자 `--text` 15px / 700 |
| 선택 칩(네모) | 높이 48px, 둥근 12px. 선택: 1.5px `--primary` 테두리 + `--primary-light` 배경 + `--primary-dark` 글자 700 |
| 선택 칩(알약) | 높이 40px, 완전 둥근 모양, 글자 14px |

| 처음 화면 파란 카드 | 둥근 18px, `--primary` 배경, 그림자 `0 6px 16px rgba(68,88,232,0.25)`, 아이콘 상자 54px |
| 하단 탭 | 3칸, 흰 배경, 위 1px `--border`, 칸 높이 64px 이상 |
| 터치 대상 | 모든 누르는 요소 높이 44px 이상 |

## 화면 폭과 배치

- 모바일 기준 폭 **390px**(콘텐츠 좌우 여백 20px). 화면 높이가 모자라면 스크롤하고, 주요 버튼은 콘텐츠 맨 아래 또는 화면 아래에 둔다.
- PC(≥ 960px): 상단 바 높이 64px(흰 배경, 아래 1px `--border`, 왼쪽 로고+"리뷰 대응 도우미", 오른쪽 고지). 본문 `grid-template-columns: 360px 1fr 1fr`, 간격 20px, 좌우 여백 32px, 바탕 `--surface`.
- 960px 미만에서는 모바일 단계별 화면을 쓴다(태블릿은 가운데 정렬, 최대 폭 480px 권장).

## 화면별 메모

| 화면 | 바탕 | 특징 |
|---|---|---|
| 처음 | 흰색 | 로고 줄 → 제목+그림 → 설명 → 카드 2개 → 안내 → 고지 → 하단 탭 |
| 캡쳐 | 어두운 `--dark` | 헤더 가운데 제목, 흰 모서리 프레임, 둥근 컨트롤(갤러리·셔터), 아래 흰 시트(위쪽만 둥근 24px) |
| 붙여넣기 | 흰색 | 입력창이 가장 크다 |
| 정보 확인·결과·답변·체크리스트 | `--surface` | 흰 카드가 쌓이는 구조 |
| 답변의 유형 칩 | — | 가로 스크롤 한 줄, 화면 양끝까지 닿게 하고 칩은 줄바꿈하지 않는다 |

## 시안을 코드로 옮길 때

`design-reference/*.dc.html`의 인라인 스타일 값이 이 문서의 값과 같다. 인라인 스타일은 CSS 클래스와 변수로 바꾸고, 같은 모양의 요소(카드·칩·버튼·안내 상자)는 **하나의 컴포넌트 스타일**로 합친다.
