# 시안 원본 읽는 법

이 폴더의 `*.dc.html`은 Claude Design 캔버스에서 만든 **시안 원본**입니다. 그대로 열어서는 동작하지 않으며(`support.js` 없음), **레이아웃·문구·색을 확인하는 참고용**입니다.

## 파일과 화면

| 파일 | 화면 (PRD 번호) | 크기 |
|---|---|---|
| `Main.dc.html` | 처음 화면 (0) | 390×880 |
| `Capture.dc.html` | 리뷰 캡쳐하기 (1a) | 390×880 |
| `Paste.dc.html` | 리뷰 붙여넣기 (1b) | 390×880 |
| `Confirm.dc.html` | 리뷰 정보 확인 (2) | 390×960 |
| `Result.dc.html` | 분석 결과 (3) | 390×1020 |
| `Reply.dc.html` | 답변 초안 (4) | 390×1060 |

| `Desktop.dc.html` | PC 3열 | 1280×1000 |
| `canvas.json` | 화면 배치 정보(무시해도 됨) | — |

## 읽는 방법

- `<x-dc>` 안이 화면 본문입니다. `style="..."` 인라인 스타일에 색·크기·간격이 모두 들어 있습니다.
- `{{ ... }}`는 값이 들어갈 자리, `<sc-for>`는 반복, `<sc-if>`는 조건 표시입니다. 실제 구현에서는 일반 JavaScript로 바꿉니다.
- 아래쪽 `<script type="text/x-dc">`의 `renderVals()`가 화면의 **상태와 동작**입니다(유형 전환, 말투 선택, 지우기, 초기화, 탭 안내). 데이터(`TYPES`, `TPL` 등)는 시안용 사본이므로 **실제 앱은 `data/review-helper/*.json`을 읽습니다.**
- 시안과 `docs/PRD.md`가 다르면 **PRD가 기준**입니다(예: 답변의 빈칸 입력칸은 시안에 없고 PRD에만 있음).
- 시안의 하단 탭 링크 `https://benefitson.org`는 임시값입니다(`HUB_URL`).
