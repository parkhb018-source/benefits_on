# Claude Code에 붙여넣을 프롬프트

## 시작하기 전에 (한 번만)

### 1. 작업 폴더가 "git 저장소"인지 확인하기

혜택on 폴더가 `benefits_on-main\benefits_on-main`처럼 이름이 겹쳐 있으면 GitHub에서 **ZIP으로 내려받은 사본**일 수 있어요. 이 경우 변경 기록(git)이 없어서 안전하게 작업할 수 없습니다.

1. 폴더 안에서 마우스 오른쪽 → "터미널에서 열기"(또는 명령 프롬프트)를 엽니다.
2. `git status`를 입력합니다.
   - 브랜치 이름이나 변경 파일 목록이 나오면 → **저장소입니다.** 그대로 진행하세요.
   - "not a git repository"라고 나오면 → **ZIP 사본입니다.** GitHub의 혜택on 저장소를 새로 복제(clone)한 폴더에서 작업해야 해요. 복제 방법은 Claude Code에게 "이 저장소를 복제하는 방법을 알려 주세요"라고 물어보면 됩니다. 기존 ZIP 폴더는 건드리지 마세요.

### 2. 패키지 넣고 시작하기

1. 받은 압축 파일을 풀어서 `review-helper-handoff` 폴더를 **저장소 맨 위 폴더**에 넣습니다.
2. 그 폴더에서 터미널을 열고 Claude Code를 실행합니다(예: `claude`).
3. 아래 **프롬프트 1**을 붙여넣습니다.
4. Claude Code가 보고하면 읽어 보고, 질문에 답한 뒤 **프롬프트 2, 3…** 순서로 진행합니다. 한 번에 다음 단계로 넘어가지 마세요.

> 팁: Claude Code가 파일 수정이나 명령 실행을 물어보면, 처음에는 하나씩 읽어 보고 승인하세요. 이상하면 "왜 필요한가요?"라고 물으면 됩니다.
> 점검 명령(`python ...`)이 안 되면 Python이 설치되지 않았거나 `py`로 써야 하는 경우예요. Claude Code에게 "Python이 설치되어 있는지 확인해 주세요"라고 시키면 됩니다.
> **`review-helper-handoff` 폴더는 작업 자료예요.** 폴더 전체를 GitHub에 올리지 않도록, 올리기 전에 꼭 Claude Code에게 어떤 파일이 올라가는지 보여 달라고 하세요.

## 프롬프트 1 — 읽고 저장소 파악하기 (0단계, 코드 수정 없음)

```
이 저장소에 "리뷰 대응도우미"라는 새 무료도구를 만들 거예요. 배달앱 사장님이 부정 리뷰를 붙여넣거나 캡쳐하면 리뷰 유형, 신고 대상 여부(참고용), 확인할 점, 답변 초안을 알려 주는 도구입니다.

먼저 review-helper-handoff 폴더의 문서를 이 순서로 읽어 주세요.
1. review-helper-handoff/CLAUDE.md
2. review-helper-handoff/docs/PRD.md
3. review-helper-handoff/docs/TASKS.md
4. review-helper-handoff/docs/DESIGN-TOKENS.md
5. review-helper-handoff/docs/OPEN-ITEMS.md
6. review-helper-handoff/data/review-helper/README.md

그다음 TASKS.md의 "0단계"만 진행해 주세요. 파일을 만들거나 수정하지 말고, 저장소를 읽기만 하세요.
- 이 폴더가 git 저장소인지(git status), Python과 Node가 설치되어 있는지
- 기존 무료도구(pages/tools 아래)가 어떻게 만들어져 있는지, 공통 CSS·헤더·푸터·GA4 코드가 어디에 있는지
- 기존 CLAUDE.md가 있는지
- 새 도구와 데이터 파일을 어디에 두는 게 좋을지

저는 개발 전문가가 아니에요. 보고는 쉬운 한국어로, 아래 세 가지로 정리해 주세요.
① 이 폴더가 git 저장소인지와 발견한 저장소 구조 ② 제안하는 폴더 위치(도구 페이지는 pages/tools/review-helper/로 정해져 있어요) ③ 저에게 묻고 싶은 것(OPEN-ITEMS 중 지금 필요한 것)
승인하기 전에는 코드를 쓰지 마세요.
```

## 중간에 막혔을 때

- 문서에 없는 질문이 나오면: "OPEN-ITEMS.md를 확인했나요? 거기 없으면 추측하지 말고 저에게 물어보세요."
- 결과가 마음에 안 들 때: 어느 화면의 어느 부분인지 구체적으로 알려 주세요. (예: "결과 화면의 유형 바꾸기 버튼이 너무 작아요")
- 정책이나 문구를 고치고 싶을 때: 코드가 아니라 `data/review-helper/*.json`을 고치면 됩니다. 고친 뒤 `python data/review-helper/validate.py`를 실행하세요.
