# Tool Evaluation Sheet — 퇴직금 실수령액 계산기

기준 문서: `05_BenefitsON_Tool_Evaluation_Framework_v1.0`

## Product Decision Filter (개발 전 필수 통과, 6개 중 5개 이상)

| 질문 | 판정 |
|---|---|
| 실제 문제를 해결하는가? | ✅ — 국세청 계산기는 존재하나 "퇴직금(근로기준법) + 퇴직소득세(세법)"를 한 화면에서 이어서 계산해주는 무료 도구는 드묾. `article-severance.html`도 세금 산식 없이 국세청으로 아웃링크만 함 |
| 하루 100명 이상 사용 가능성이 있는가? | ✅ — "퇴직금 계산기" 계열 키워드는 검색량이 꾸준한 상시 수요 키워드 |
| 정부지원 또는 세무·노무이슈와 관련 있는가? | ✅ — 근로자퇴직급여보장법·소득세법 |
| 서버 없이 구현 가능한가? | ✅ — 입력값 기반 순수 계산, 외부 API 불필요 |
| 개인정보 없이 가능한가? | ✅ — 급여·근속기간은 저장하지 않고 브라우저 내 계산만 수행 |
| 기존 유사 서비스보다 간단한가? | ⚠️ 보통 — nodong.kr 등 기존 계산기 대비 결정적 차별점은 "UX 단순화(입력 5개)"이며 기능적으로는 동등 |

**판정: 6개 중 5개 통과 → 개발 진행 가능**

## Evaluation Criteria (100점 만점)

| 항목 | 배점 | 채점 | 근거 |
|---|---:|---:|---|
| 문제해결력 | 25 | 22 | 세후 실수령액까지 원스톱 계산은 명확한 공백을 메움. 다만 100% 신규 문제는 아니고 기존 도구들의 UX 통합에 가까움 |
| 사용자 수요 | 20 | 18 | 검색 키워드 수요 존재(섹션 16 SEO 키워드 목록), 다만 경쟁 계산기 다수 |
| BenefitsON 적합성 | 15 | 15 | 정부지원/노무/세금 카테고리, 소상공인·근로자 대상 정확히 부합 |
| 차별성 | 10 | 6 | 계산 로직 자체는 동일 법령 기반이라 경쟁사와 유사. 차별점은 UX(입력 5개, 즉시 결과)와 IRP 이연 고지 등 실무 정확도 |
| Serverless 가능성 | 10 | 10 | 완전 브라우저 계산 |
| 개발 난이도 | 10 | 6 | 세율 구간·연분연승법 로직이 다단계라 `youth-deposit-calculator` 대비 복잡도 높음(3일 내외 예상) |
| 유지보수 용이성 | 5 | 4 | 세율표는 법 개정 시에만 변경(연 1회 미만), `data/*.json` 분리로 정책 변경 대응 쉬움 |
| SEO 가치 | 5 | 5 | "퇴직금 계산기" 계열 키워드는 상시 검색 카테고리 |
| **합계** | **100** | **86** | |

**Priority Level: 86점 → A등급(다음 개발)** — 지시서에서 이미 High priority로 지정했으므로 즉시 착수로 처리.

## Stop Rule 점검 (Product Strategy 문서 12번)

- Brand Identity 부합: ✅ (신뢰·전문성·명확함 — 세법 공식 출처 명시로 부합)
- Product Strategy 부합: ✅ (Serverless/Privacy/Zero Install/Fast/Explainable 전부 충족 가능한 설계)
- 실제 문제 해결: ✅
- 장기적 플랫폼 가치: ✅ (세금/노무 계산기 카테고리 확장의 기반)

→ **Stop Rule 미해당, 개발 진행**
