# QA Test Cases — 퇴직금 실수령액 계산기

기준 문서: `11_BenefitsON_QA_Test_Standard_v1.0`. 기능 테스트 기대값은 `02_Rule_Engine_Retirement_Pay.md`의 공식을 Node.js로 그대로 구현해 역산했다(스크립트는 코딩 단계에서 `engine/retirement-pay-calculator.test.js`의 기반이 된다). 임의로 만든 기대값 없음.

**2차 검증 반영**: 원 단위 미만은 절사(내림) 적용(SRC-11, 국고금 관리법 제47조**제2항** 근거) — 1차 산출물에서는 반올림을 사용했으나 아래 표는 절사 기준으로 재계산한 확정값이다(반올림 대비 최대 수 원 차이).

**3차 검증 재확인**: 과세표준 단계에도 1원 미만 절사를 적용(법적 근거 명확, SRC-11)한 값과 중간 계산을 소수점 그대로 유지한 뒤 최종 단계에서만 절사한 값을 10개 시나리오 전체에 대해 각각 계산해 대조했다. **모든 케이스에서 최종 퇴직소득세·지방소득세가 원 단위까지 동일**했으므로 아래 표는 변경 없이 유지한다.

### Case 10 상세 (예외 처리)

| 입력 | 기대 동작 |
|---|---|
| 퇴사일이 입사일보다 빠름 | 계산 실행하지 않고 "퇴사일은 입사일 이후여야 합니다" 오류 표시 |
| 월급여 ≤ 0 또는 미입력 | "급여는 0보다 커야 합니다" 오류 표시 |
| 재직일수 < 365일 | LAW-RET-01에 의해 "법정 퇴직금 지급 대상이 아닙니다" 안내(오류 아님, 정상 분기) |

### Case 08/08b 경계값 검증 포인트

- 근속연수공제 구간은 "n≤5, 5<n≤10, 10<n≤20, n>20" — 정확히 10년/20년은 각각 두 번째·세 번째 구간(초과가 아닌 이하)에 귀속되어야 함. 위 계산은 이 경계 규칙대로 산출됨(`taxServiceYears`가 10, 20을 반환할 때 각각 5,000,000+(10-5)×2,000,000=15,000,000 / 15,000,000+(20-10)×2,500,000=40,000,000이 아닌 40,000,000+(20-20)×3,000,000=40,000,000으로 20년 구간 진입 직전 값과 일치하는지 코딩 단계에서 unit test로 재확인).
