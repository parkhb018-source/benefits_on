# Rule Engine 설계 — 퇴직금 실수령액 계산기

기준 문서: `08_BenefitsON_Rule_Engine_Standard_v1.0`. 카테고리 접두어는 기존 예시(DLV=배달, LAW=법률, SUP=정부지원, CAL=계산, BIZ=사업자이슈)에 세금 규칙이 없어 **`TAX`(세금)** 를 신설한다. 노무 지급요건은 `LAW`, 순수 산술 규칙은 `CAL`을 사용한다.

## 표준 면책문구 (Rule Engine Standard 17번, 그대로 적용)

> 본 결과는 참고용 안내입니다. 실제 권리관계 및 지급 대상 여부는 관계기관 또는 전문가의 확인을 받으시기 바랍니다.

추가로 이 도구 전용 고지(IRP 이연 관련, SRC-07 근거)를 덧붙인다:

> 만 55세 미만이며 퇴직급여가 300만원을 초과하는 경우, 퇴직금은 원칙적으로 IRP(개인형 퇴직연금) 계좌로 지급되고 세금은 실제 인출 시점까지 이연됩니다. 이 경우 아래 "예상 세후 실수령액"은 즉시 현금으로 받는 금액이 아니라 향후 부담할 것으로 예상되는 세금을 미리 계산한 참고값입니다.

**2차 검증(정확한 평균임금 관련) 결론**: 이 계산기의 "평균임금"은 근로기준법상 법정 평균임금의 **근사치(간편 계산)**다. 정확한 법정 평균임금은 3개월간 실제 임금대장 및 수습·휴업 등 제외기간 반영이 필요해 5개 입력 필드로는 재현 불가능하다(§CAL-RET-01 비고 참조). 이에 따라 결과 명칭을 **"예상 퇴직금(간편 계산)"**으로, 관련 필드 레이블에는 "간편 계산 결과이며 실제 평균임금과 다를 수 있습니다"를 부제로 명시한다. "세후 실수령액"이라는 표현은 IRP 이전 시 실제 현금 수령액과 다를 수 있으므로 최종 결과 라벨은 **"예상 세후 금액(퇴직소득세·지방소득세 제외 후)"**으로, 하단에 IRP 해당 여부에 따라 "실제 수령 방식(현금 vs IRP)에 따라 달라질 수 있음"을 함께 고지한다.

## LAW-RET-01 — 계속근로기간 지급요건

```
IF   계속근로기간(재직일수) < 365일
THEN 법정 퇴직금 지급 대상이 아닙니다.
BECAUSE 근로자퇴직급여 보장법 제4조제1항 단서 — 계속근로기간 1년 미만은 지급 의무 없음
ACTION  계산을 중단하고 안내 메시지만 표시(세금 계산 진행하지 않음)
```
Priority: Critical · Source: SRC-01 · Category: LAW

## LAW-RET-02 — 소정근로시간 지급요건

```
IF   4주 평균 1주 소정근로시간 < 15시간
THEN 법정 퇴직금 지급 대상이 아닙니다.
BECAUSE 근로자퇴직급여 보장법 제4조제1항 단서
ACTION  계산을 중단하고 안내 메시지만 표시
```
Priority: Critical · Source: SRC-01 · Category: LAW
비고: MVP는 입력 항목 5개 제한으로 이 값을 직접 입력받지 않는다. 대신 "주 15시간 미만 근무자이신가요?"를 결과 하단 안내 문구로만 노출(체크박스 미도입) — PRD 09번 섹션에서 최종 확정.

## CAL-RET-01 — 평균임금 산정

```
IF   입력값(입사일, 퇴사일, 3개월 평균 월급여, 기타수당 연간총액) 유효
THEN 1일 평균임금 = (3개월 평균 월급여×3 + 기타수당 연간총액×3/12) ÷ (퇴사일 기준 역산 3개월의 총일수)
BECAUSE 근로기준법 제2조제1항제6호, 시행령 제2조 — 사유발생일 이전 3개월간 임금총액÷총일수
ACTION  평균임금 < (월급여÷월평균 소정근로시간 기반 통상임금) 인 경우 통상임금으로 대체 — MVP는 이 비교를 사용자에게 별도 입력받지 않고 생략하며, 결과 안내문에 "평균임금이 통상임금보다 낮다면 통상임금 기준으로 재계산됩니다"라는 고지만 표시(계산 로직 미구현, 명시적 스코프 제외)
```
Priority: High · Source: SRC-03, SRC-10 · Category: CAL

**비고 (2차 검증에서 확인)**: 근로기준법 시행령 제2조는 평균임금 산정기간 중 ①수습기간(3개월 이내) ②사용자 귀책 휴업 ③출산전후휴가·유산사산휴가 ④업무상 재해 요양휴업 ⑤육아휴직 ⑥쟁의행위기간 ⑦병역의무이행기간 ⑧사용자 승인 휴업이 있으면 그 기간과 그 기간 중 지급된 임금을 산정기간·임금총액에서 각각 제외하도록 규정한다. 또한 "임시로 지급된 임금·수당"과 "통화 외의 것으로 지급된 임금"은 평균임금에 산입하지 않는다. 이 계산기의 "3개월 평균 월급여" 근사 입력은 위 예외기간·제외항목을 반영하지 않으므로 **법정 평균임금과 정확히 일치하지 않을 수 있다** — 결과 UX에 반드시 고지(§Header 2차 검증 결론 참조).

## CAL-RET-02 — 법정 퇴직금 산출

```
IF   LAW-RET-01, LAW-RET-02 모두 통과
THEN 퇴직금 = 1일 평균임금 × 30 × (재직일수 ÷ 365), 원 단위 미만 절사(내림)
BECAUSE 근로자퇴직급여 보장법 제8조
ACTION  결과 화면 최상단 "세전 예상 퇴직금(간편 계산)"으로 표시
```
Priority: Critical · Source: SRC-02 · Category: CAL

## TAX-RET-01 — 세금계산용 근속연수(절상)

```
IF   재직 개월수 ÷ 12 에 소수점 단수가 있음
THEN 세금계산용 근속연수 = 올림(재직개월수 ÷ 12), 최소 1년.
     세부 산정: 근속연수 = (총근속월수 − 중복월수) ÷ 12. 1개월 미만의 기간은 1개월로,
     그 결과 1년 미만의 월수(단수)는 1년으로 본다.
BECAUSE 소득세법 시행령 제42조의2(퇴직소득의 범위 및 근속연수 계산) — 퇴직소득공제(근속연수공제) 산정의 기초가 되는
     근속연수 계산방법을 정한 조항. 최종 검증(3차)으로 "제203조 추정"을 정정해 확정.
ACTION  이 값은 CAL-RET-02의 "재직일수/365" 비율(퇴직금 산정용, 절상 없음)과 별개로 관리
```
Priority: High · Source: SRC-06(3차 검증으로 확정 — 소득세법 시행령 제42조의2) · Category: TAX

**비고 (3차 검증)**: 시행령 제203조는 별도 조항으로, 같은 과세기간에 퇴직소득이 2회 이상 발생해 "정산"이 필요한 경우의 근속연수 합산 규정이다(MVP 제외 범위인 "동일연도 복수 퇴직소득" 케이스에 해당). 일반적인 1회 퇴직 시 근속연수공제의 근속연수 산정 근거는 제42조의2이며, 이번 계산기(1회 퇴직만 다루는 MVP)에는 제42조의2만 적용된다.

## TAX-RET-02 — 근속연수공제

```
IF   TAX-RET-01의 근속연수(n) 확정
THEN n≤5: n×100만원
     5<n≤10: 500만원+(n-5)×200만원
     10<n≤20: 1,500만원+(n-10)×250만원
     n>20: 4,000만원+(n-20)×300만원
BECAUSE 국세청 퇴직소득세 계산방법 — 근속연수공제표(2020년 이후 퇴직자 적용)
ACTION  퇴직소득금액(=퇴직금)에서 이 값을 차감해 환산급여 계산에 사용
```
Priority: High · Source: SRC-04 · Category: TAX

## TAX-RET-03 — 환산급여

```
IF   TAX-RET-02 완료
THEN 환산급여 = (퇴직소득금액 − 근속연수공제) ÷ 근속연수 × 12
BECAUSE 국세청 퇴직소득세 계산방법
ACTION  음수 방지: (퇴직소득금액 − 근속연수공제) < 0 이면 0으로 clamp
```
Priority: High · Source: SRC-04 · Category: TAX

## TAX-RET-04 — 환산급여공제

```
IF   환산급여(c) 확정
THEN c≤800만원: 전액공제
     800만원<c≤7,000만원: 800만원+(c-800만원)×60%
     7,000만원<c≤1억원: 4,520만원+(c-7,000만원)×55%
     1억원<c≤3억원: 6,170만원+(c-1억원)×45%
     c>3억원: 1억5,170만원+(c-3억원)×35%
BECAUSE 국세청 퇴직소득세 계산방법
ACTION  과세표준 산출에 사용
```
Priority: High · Source: SRC-04 · Category: TAX

## TAX-RET-05 — 과세표준 및 산출세액(연분연승법)

```
IF   TAX-RET-04 완료
THEN 과세표준 = 환산급여 − 환산급여공제 (음수면 0), 원 단위 미만 절사(★법적 근거)
     환산산출세액 = 과세표준×세율 − 누진공제액 (기본세율 8단계표)
     퇴직소득 산출세액 = 환산산출세액 ÷ 12 × 근속연수, 원 단위 미만 절사(관행)
BECAUSE 국세청 퇴직소득세 계산방법 — 연분연승법
ACTION  결과 화면 "예상 퇴직소득세"로 표시
```
Priority: Critical · Source: SRC-04, SRC-11 · Category: TAX

**비고 (3차 검증 — 원 단위 처리 최종 확정)**:
- **과세표준(★법적 근거 명확)**: 국고금 관리법 제47조**제2항**이 "국세의 과세표준액을 산정할 때 1원 미만의 끝수가 있으면 이를 계산하지 아니한다"고 명문으로 규정 — 과세표준 단계는 이 조항을 직접 적용한다.
- **최종 산출세액·지방소득세(관행 적용)**: 국고금 관리법 제47조에 퇴직소득세·지방소득세 "산출세액" 자체를 절사하라는 별도 조항은 없다. 제1항(국고금 수입·지출 10원 미만 절사)은 국고 실제 수납액에 관한 조항이라 계산기의 "예상 세액 표시"에 문언 그대로 적용되진 않는다. 다만 과세표준을 절사한 상태로 계산을 이어가면 결과적으로 원단위 이하가 자연히 정리되고, 소액(1원 미만) 오차만 남는 수준이라 실무 관행에 따라 최종 표시값도 절사(내림)로 통일한다 — **이 부분은 소득세법령상 퇴직소득세 전용 조항을 찾지 못해 [확인 필요]로 유지**.
- **영향도 검증**: 과세표준 단계에서 절사를 적용하는 방식과 적용하지 않는 방식(중간값 소수점 유지 후 최종 절사)을 04번 QA 문서의 10개 시나리오 전체에 대해 각각 계산해 비교한 결과, **모든 케이스에서 최종 산출세액·지방소득세가 원 단위까지 동일**하게 나왔다(과세표준의 1원 미만 차이가 세율 적용 후 반올림 경계를 넘기지 않음). 따라서 04번 문서의 기존 기대값은 수정 없이 유지한다.

## TAX-RET-06 — 지방소득세

```
IF   TAX-RET-05 완료
THEN 지방소득세 = 퇴직소득세 × 10%, 원 단위 미만 절사(내림)
BECAUSE 지방세법 제91조·제92조
ACTION  결과 화면 "예상 지방소득세"로 표시
```
Priority: High · Source: SRC-05, SRC-11 · Category: TAX

## TAX-RET-07 — 예상 실수령액 및 IRP 고지

```
IF   TAX-RET-05, TAX-RET-06 완료
THEN 예상 세후 금액 = 퇴직금 − 퇴직소득세 − 지방소득세
BECAUSE 위 규칙들의 합성
ACTION  결과 화면 최상단에 "예상 세후 금액(퇴직소득세·지방소득세 제외)"으로 강조 표시. 입력된 나이 < 55 AND 퇴직금 > 300만원이면 TAX-RET-07-IRP 고지문 함께 노출
```
Priority: Critical · Source: 합성 규칙(SRC-02, SRC-04, SRC-05) · Category: TAX

## TAX-RET-07-IRP — IRP 의무이전 고지

```
IF   나이 < 55 AND 퇴직금 > 3,000,000원
THEN "이 금액은 원칙적으로 IRP 계좌로 이전되며 실제 인출 시까지 과세가 이연될 수 있습니다" 고지 표시
BECAUSE 근로자퇴직급여 보장법 제9조제2항 단서 및 시행령 — 퇴직급여는 원칙적으로 근로자의 IRP 계좌로 지급. 예외: ①55세 이후 퇴직 ②퇴직급여 300만원 이하 ③사망으로 인한 당연퇴직·외국인 근로자 국외 출국 ④타 법령에서 퇴직소득 공제를 인정하는 경우
ACTION  결과 카드 내 안내 박스(`.info-box`)로 표시, 계산값 자체는 변경하지 않음
```
Priority: High · Source: SRC-07(2차 검증으로 제9조제2항 확인 완료, 시행령 예외 4개 항목은 고용노동부 자료로 교차검증) · Category: TAX

## Rule Conflict Policy

LAW-RET-01/02가 우선순위 Critical로 다른 모든 규칙보다 먼저 평가되며, 둘 중 하나라도 조건에 해당하면 `stopEvaluation`(이후 CAL/TAX 규칙 평가 중단, 안내 메시지만 표시) — `goodwill-protection-check`의 `evaluator.js` priority-sort + `stopEvaluation` 컨벤션을 그대로 채택.
